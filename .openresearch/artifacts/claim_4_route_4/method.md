# Claim 4 route 4: mandatory adversarial falsification

Three deterministic processes synthesize 6,000 reciprocal four-alternative probability systems on a denominator-20 grid. The SMT checker first retains only systems that have no strictly order-preserving utility-difference representation. Each retained target is then tested against all `16^6` monotonicity sextuples on the complete lottery domain at `alpha=1/2` using exact integers.

A candidate can be called a counterexample only after a second, independently implemented exhaustive-loop checker agrees. Reciprocity analytically provides expandability and every LCS obligation for all nontrivial `alpha`.

The positive control is an exact linear utility-difference system. The negative control is a cyclic non-representable system that must be rejected by monotonicity.
